Высоконагруженный микросервисный бэкенд для аналога Pixel Battle (VK / Reddit r/place).
Технологии: FastAPI — асинхронный фреймворк и WebSockets, Redis — хранение кадра в оперативке, TTL для кулдауна (30 сек) и Pub/Sub для мгновенной рассылки всем клиентам, ClickHouse — колоночная БД для сохранения полной истории кликов (для будущего таймлапса), Docker Compose — контейнеризация, HTML5 Canvas & JS — интерактивный клиент.
Запуск: клонируйте репозиторий, docker compose up --build
После запуска:
1. Бэкенд доступен по адресу: http://localhost:8000
2. Откройте index.html в браузере, чтобы начать рисовать.

Схема работы:
1. Клиент подключается по WebSocket к /ws.
2. При клике проверяется кулдаун пользователя в Redis (EX = 30s).
3. При успехе:
   - Обновляется состояние холста в Redis Hash.
   - Запись отправляется в ClickHouse (pixel_history).
   - Событие публикуется в Redis Pub/Sub и улетает всем подключенным WebSocket-клиентам.
